# buffer_energy_status
## 实时监控机器人的缓冲能量状态，通过进度条和文本直观展示能量上限与当前余量
1. _on_static 静态状态回调，用于解析并更新缓冲能量的最大值上限

2. _on_dynamic 动态状态回调，用于实时解析并更新当前的缓冲能量数值

3. _apply 核心 UI 刷新函数，同步更新进度条的数值范围及文本标签的百分比显示

4. _reset UI 重置函数，在初始化或数据异常时恢复默认的零值状态

5. _get_val 安全取值工具函数，支持从字典或对象中提取能量字段，防止脚本报错

6. _resolve_game_state 自动解析游戏状态管理节点的路径或单例引用

7. 剩余均为初始化或工具函数
# chassis_energy_status

6. _get_val 安全取值工具函数，兼容多种数据结构（字典、对象方法）获取能量字段

# robot_cooldown_rate
## 实时监控并展示机器人射击热量的每秒冷却速率
1. _on_static 静态状态回调，解析并获取机器人最新的每秒冷却速率（Heat Cooldown Rate）

2. _apply UI 刷新函数，格式化冷却速率数值并更新到富文本标签，若数值无效则显示缺省符号

3. _reset UI 重置函数，将冷却速率清零并恢复初始显示状态

4. _resolve_game_state 自动解析并获取游戏状态管理节点的单例或路径引用

5. 剩余均为初始化或工具函数
# robot_running_info
## 实时监控目标机器人的远程补给权限、脱战状态及脱战倒计时
1. _on_dynamic 动态状态回调，解析目标机器人的数据，更新其远程加血、远程补弹权限，以及当前的脱战状态与倒计时

2. _apply 核心 UI 刷新函数，将逻辑状态（布尔值）转换为直观的文字描述，并根据战斗状态动态切换倒计时标签的可见性

3. _pick_entry 筛选逻辑函数，支持从复杂数据结构中根据 target_robot_id 匹配特定机器人条目

4. _reset UI 重置函数，在初始化或数据异常时恢复到默认状态（如显示“否”、“战斗中”）

5. _get_val 安全取值工具函数，兼容多种数据源格式以获取运行信息相关的字段

6. _resolve_game_state 自动解析并获取游戏状态管理节点的单例或路径引用

7. 剩余均为初始化或工具函数
# robot_shootor_status
## 通过自定义绘制十字准星与环形进度条，实时展示机器人的射击热量状态与上限
1. _draw 核心绘制函数，利用 draw_arc 和 draw_line 实时渲染背景环、动态热量环以及十字准星 UI。

2. _heat_color 颜色过渡算法，根据热量占比实现从“绿色（安全）”到“黄色（预警）”再到“红色（过热）”的平滑渐变。

3. _on_static / _on_dynamic 状态回调，分别从静态和动态数据源中提取热量上限与当前热量值，并触发 queue_redraw 请求重绘。

4. _pick_entry 数据筛选逻辑，支持根据 target_robot_id 从字典或数组中精准匹配目标机器人。

5. set_heat 提供外部手动更新热量数值的接口，并同步更新 UI 表现。

6. _resolve_game_state 自动解析并获取游戏状态管理节点的单例或路径引用。

7. 剩余均为初始化或工具函数
