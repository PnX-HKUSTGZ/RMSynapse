# base
## 用于管理和展示基地（Base）的核心属性，包括血量、护盾值及装甲无敌状态
1. _base_status_to_string：将基地状态 ID 转换为可读的中文描述（无敌、装甲闭合、装甲开放）。

2. set_base_max_hp / set_base_current_hp：更新基地血量条的最大值与当前值，同步刷新对应的文本标签。

3. set_shield_hp：实时更新并显示基地的护盾血量。

4. set_base_status：通过状态 ID 改变并显示基地当前的防御状态（如是否处于无敌或装甲开放状态）。

5. _ready：初始化 UI 元素，设置血量条与标签的初始显示数值。

6. 剩余均为工具函数：包括 @export 属性定义及状态常量映射。
# global_unit_state
## 实时监控并更新红蓝双方所有机器人单位及基地的血量、护盾与防御状态
1. _signal_callback 信号回调核心，解析原始血量数组并根据阵营（Side）和比赛阶段（Stage）将数据分发至我方与敌方队列

2. _update_unit_states 遍历并更新场景树中对应单位节点的当前血量显示

3. _update_base_shield 同步更新双方基地的实时血量、护盾值以及装甲无敌状态

4. _ready 初始化逻辑，根据编辑器配置的阵营和比赛阶段自动匹配节点路径映射表

5. 剩余均为工具函数
# outpost
## 管理并展示单个机器人单位的基础状态，包括血量条进度与状态描述文字
1. set_max_hp：更新血量条（ProgressBar）的最大值上限。

2. set_current_hp：更新血量条的当前数值。

3. set_state：设置并显示单位的当前状态字符串（如“存活”、“阵亡”等）。

4. _ready：初始化 UI 引用，根据导出的变量值（@export）设置血量条和标签的初始状态。

5. 剩余均为初始化或工具函数：包括基础属性变量的声明与定义。
