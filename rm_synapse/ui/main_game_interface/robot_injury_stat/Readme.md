# 实时统计机器人受到的各类伤害来源，并在机器人被击毁时通过饼图和图例直观展示伤害占比
1. _on_dynamic_status：监听机器人实时血量，当检测到血量从正值变为零（即机器人被击毁）时，触发伤害统计图表的显示。

2. _show_chart：核心展示逻辑，计算各项伤害分片数据，重置显示计时器，并调用绘图系统。

3. _draw：底层绘图函数，根据各伤害来源的比例（ratio），在 UI 上动态绘制多边形饼图及背景圆环。

4. _build_segments：解析伤害统计实例，根据 DAMAGE_FIELDS 定义的颜色和键值计算每种伤害（如撞击、17mm、判罚等）的数值与占比。

5. _update_legend：更新富文本标签（RichTextLabel），显示总伤害、击杀者 ID 以及各分项伤害的详细数值与百分比。

6. _get_val：安全取值工具函数，兼容字典、对象方法或属性访问，确保数据解析的稳定性。

7. 剩余均为工具函数：包括 DAMAGE_FIELDS 颜色常量定义、信号连接以及 _process 自动倒计时隐藏逻辑。
