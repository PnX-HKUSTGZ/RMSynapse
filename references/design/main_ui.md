# 自定义客户端主 UI 功能规格

本文定义自定义客户端主页面应包含的功能、展示与交互。主页面是操作手比赛中默认停留的页面，目标是在不干扰图传视野和鼠标控视角的前提下，快速回答四类问题：

- 当前胜负态势如何：基地、前哨站、比分、阶段、剩余时间和全队伤害是否支持当前战术。
- 本机能否继续作战：血量、热量、弹量、底盘能量、缓冲能量、模块状态、Buff 和脱战状态是否允许继续交战。
- 是否有必须立刻响应的事件：判罚、遮挡、战亡、基地被攻击、前哨站被摧毁、飞镖、空中支援、能量机关、装配结果。
- 当前角色能执行哪些操作：补血、补弹、复活、性能体系、部署模式、哨兵姿态、飞镖、空中支援、能量机关等。

主 UI 的设计原则：

- 常驻信息只放高频判断所需内容。
- 操作入口默认收起，右侧以按键唤出的弹窗形式出现。
- 弹窗打开后展示相关状态、费用、可用性和回执，不只放按钮。
- 鼠标尽量只用于控制图传视角，不在主 UI 上承担地图标记、按钮点击等高风险操作。
- 主 UI 小地图只做态势展示，不做点击标记；复杂地图交互放到独立地图页面。

## 1. 页面结构

主 UI 采用“顶部全局态势 + 左侧告警 + 中央图传 HUD + 右侧弹窗交互 + 右下只读小地图 + 底部本机状态”的结构。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ A 顶部全局态势：阶段/时间/比分/基地/前哨/双方机器人血量/经济/链路             │
├───────────────┬──────────────────────────────────────────────┬───────────────┤
│ B 告警事件流   │ C 图传主视野 + 准星/热量/弹量/锁定/Buff        │ D 右侧弹窗区域 │
│ E 模块状态摘要 │                                              │ 默认收起       │
│               │                                              │ 按键唤出       │
│               │                                              │ F 只读小地图   │
├───────────────┴──────────────────────────────────────────────┴───────────────┤
│ G 底部本机状态 / 特殊角色状态条                                               │
└──────────────────────────────────────────────────────────────────────────────┘
```

常驻区域建议：

| 区域 | 作用 | 常驻程度 |
| --- | --- | --- |
| 顶部全局态势 | 胜负目标、队伍资源、双方机器人血量 | 始终显示 |
| 左侧告警事件流 | 当前必须关注的高优先级事件 | 始终显示，可短时强调 |
| 中央图传 HUD | 射击、生存和锁定状态 | 始终显示，尽量少遮挡 |
| 右侧弹窗区域 | 角色操作、机制操作、详细状态 | 默认收起，按键打开 |
| 右下小地图 | 机器人位置、雷达目标、基地/前哨态势 | 始终显示，只读 |
| 底部状态条 | 本机资源、Buff、脱战、经验/等级 | 始终显示 |

## 2. 全局态势展示

顶部全局态势条承担“是否能赢、该打哪里、谁还活着”的判断。它不应只显示时间，而应把胜负相关信息集中在一条稳定区域。

应展示：

- 当前局号和总局数。
- 当前阶段：未开始、准备阶段、自检阶段、倒计时、比赛中、结算中。
- 阶段剩余时间和已过时间。
- 暂停状态。
- 红蓝比分。
- 己方基地血量、护盾、状态：无敌、护甲未展开、护甲展开。
- 对方基地血量、护盾、状态。
- 己方前哨站血量、状态：无敌、旋转、停转、被击毁不可重建、被击毁可重建、重建中。
- 对方前哨站血量和状态。
- 己方当前经济、累计经济、科技等级、加密等级。
- 双方机器人血量概览。
- 己方累计伤害、对方累计伤害，可作为时间耗尽时的胜负参考。
- MQTT、图传、自定义数据等关键链路状态。

机器人血量概览建议按协议顺序稳定显示：

```text
己方 1 2000 | 2 400 | 3 380 | 4 DEAD | 7 530
敌方 1 1800 | 2 ? | 3 60 LOW | 4 DEAD | 7 400
```

显示规则：

- 低血量显示 `LOW`。
- 血量为 0 显示 `DEAD`。
- 无数据显示 `?`，并灰化。
- 数据过期显示弱闪或时间戳。
- 被雷达特殊标识、易伤、离线、复活中等状态以短标签附加，不抢占血量主体。

信息来源：

- `GameStatus`
- `GlobalUnitStatus`
- `GlobalLogisticsStatus`
- 本地链路监控

## 3. 中央图传与射击 HUD

中央区域以图传画面为主体。HUD 只放射击和即时生存信息，避免遮挡视野。

应展示：

- 准星。
- 当前热量环：当前热量 / 热量上限。
- 剩余允许发弹量。
- 最近一次弹丸射速。
- 发射机构锁定状态。
- 当前可继续射击的粗略余量。
- 关键 Buff 小图标：攻击、防御、易伤、热量冷却、回血、底盘功率。
- 被遮挡或图传不可用的原因。

热量环建议：

- 0%~60%：冷色。
- 60%~85%：黄色。
- 85%~100%：橙红色。
- 超热、超射速、测速模块离线、空中反制锁定时红色强调。

图传不可用时，中央区域不能空白，应显示替代态势：

```text
图传不可用
原因：英雄部署模式 / 图传模块离线 / 判罚遮挡 / 飞镖遮挡
本机状态：HP、热量、弹量、坐标、朝向
可用操作：退出部署 / 等待遮挡结束 / 查看模块状态
```

信息来源：

- `RobotStaticStatus`
- `RobotDynamicStatus`
- `RobotModuleStatus`
- `Buff`
- `DeployModeStatusSync`
- `PenaltyInfo`
- `Event`

## 4. 本机状态展示

底部状态条显示当前操控机器人自身状态。它负责承载比中央 HUD 更完整的本机信息，但仍保持单行或双行，不做大面板。

应展示：

- 当前血量 / 最大血量。
- 当前热量 / 最大热量。
- 热量冷却速率。
- 最近弹丸射速。
- 当前底盘能量 / 最大底盘能量。
- 当前缓冲能量 / 最大缓冲能量。
- 当前经验值、距离升级所需经验、等级。
- 累计已发弹量。
- 剩余允许发弹量。
- 是否脱战、脱战倒计时。
- 是否可远程补血。
- 是否可远程补弹。
- 当前性能体系：发射机构、底盘。
- 连接、上场、存活状态。

示例：

```text
HP 1650/2000 | 热量 42/100 冷却 30/s | 弹量 238 | 弹速 18.2m/s |
底盘 2850/40000 | 缓冲 400/500 | LV.6 EXP 3100/+220 | 脱战 5s | 远程补血✓ 补弹×
```

信息来源：

- `RobotStaticStatus`
- `RobotDynamicStatus`
- `RobotPerformanceSelectionSync`
- `Buff`

## 5. 告警与事件展示

左侧为战术告警中心，分为“当前告警”和“事件流”。当前告警只显示 3 条以内，事件流保留最近 6~8 条。

高优先级告警：

- 基地遭到攻击。
- 己方基地护甲展开。
- 己方前哨站被摧毁。
- 本机战亡或待复活。
- 黄牌、红牌、超功率、超热量、超射速。
- 图传遮挡、自定义 UI 遮挡、小地图遮挡。
- 发射机构锁定。
- 关键模块离线：主控、图传、定位、测速、装甲、裁判系统关键模块。
- 空中机器人被雷达反制锁定。

中优先级告警：

- 前哨站可重建或重建中。
- 能量机关可激活、正在激活、已激活。
- 飞镖闸门开启、飞镖命中。
- 空中支援开始、付费支援正在消耗金币。
- 敌方关键机器人低血量。
- 雷达特殊标识或易伤目标出现。
- 哨兵姿态切换结果。
- 装配四级缓冲、装配失败、装配成功。

低优先级事件：

- 普通 Buff 获得或失效。
- 机器人状态恢复。
- 链路恢复。
- 普通击杀日志。

事件来源：

- `Event`
- `PenaltyInfo`
- `GlobalUnitStatus`
- `RobotModuleStatus`
- `RobotRespawnStatus`
- `RuneStatusSync`
- `DartSelectTargetStatusSync`
- `SentryCtrlResult`
- `AirSupportStatusSync`
- `TechCoreMotionStateSync`

## 6. Buff 展示

主 UI 需要同时展示“本机 Buff”和“全局/队伍关键 Buff”。Buff 必须显示增益类型、数值和剩余时间。

Buff 类型：

- 攻击增益。
- 防御增益。
- 负防御增益，即易伤。
- 射击热量冷却增益。
- 底盘功率增益。
- 回血增益。
- 可兑换允许发弹量。
- 地形跨越增益预备状态。

展示建议：

- 中央 HUD 只显示图标和剩余时间。
- 底部状态条显示本机详细数值。
- 左侧告警只显示高影响 Buff，例如易伤、强防御、大能量机关增益、飞镖导致增益失效。
- 右侧弹窗可显示完整 Buff 列表。

信息来源：

- `Buff`
- `RuneStatusSync`
- `Event`

## 7. 只读小地图

主 UI 的右下小地图只做态势展示，不做点击标记，不承担地图指挥命令。这样可以避免鼠标离开视角控制，降低误触。

应展示：

- 己方机器人位置和朝向。
- 雷达识别到的敌方机器人位置。
- 雷达特殊标识或高亮目标。
- 基地、前哨站。
- 本机位置和朝向。
- 哨兵路径规划的简化轨迹。
- 关键事件短暂闪烁：基地被攻击、飞镖命中、前哨被摧毁。

不在主 UI 小地图中展示：

- 点击标记。
- 复杂图层开关。
- 完整路径数组细节。
- 所有场地增益点详细文字。
- 地图坐标调试数据。

交互规则：

- 小地图默认 `pointer-events: none` 或等价处理。
- 鼠标移动、拖拽、点击不应被小地图捕获。
- 如需大地图，可通过键盘打开独立地图页或全屏地图层。
- 地图标记、路径规划编辑等复杂操作不属于主 UI。

信息来源：

- `RobotPosition`
- `RadarInfoToClient`
- `RobotPathPlanInfo`
- `GlobalUnitStatus`
- `Event`

## 8. 右侧弹窗式交互界面

右侧不做常驻操作栏，而是按键唤出的弹窗式交互界面。默认主屏右侧只保留小地图和少量状态摘要；操作面板打开时从右侧滑出或浮出，覆盖右侧区域，但不遮挡准星。

设计目标：

- 比赛中鼠标主要用于控制视角。
- 操作用键盘打开、键盘选择、键盘确认。
- 弹窗内同时展示状态和按钮，避免操作手盲按。
- 每个命令都显示可用性、费用、倒计时、失败原因和回执。

推荐交互方式：

```text
Tab / CapsLock：打开或关闭右侧交互弹窗
Q / E：切换弹窗分页
1~9：选择当前页的操作项
Enter / Space：确认
Esc：取消或关闭
Backspace：返回上一级
鼠标：继续保留给视角，不作为主操作输入
```

弹窗分页建议：

| 分页 | 内容 |
| --- | --- |
| 快捷 | 当前角色最常用 6~9 个操作 |
| 资源 | 补血、补弹、兑换允许发弹量、复活 |
| 角色 | 英雄部署、步兵能量机关、哨兵姿态/指令、空中支援 |
| 机制 | 飞镖、能量机关、科技核心、堡垒/特殊机制状态 |
| 状态 | Buff、模块、链路、判罚、回执日志 |

弹窗通用布局：

```text
┌────────────────────────────┐
│ 角色：哨兵  金币：620       │
│ 状态：半自动  姿态：移动    │
├────────────────────────────┤
│ 1 远程补弹      可用        │
│ 2 远程回血      200 金币    │
│ 3 确认复活      读条 8/10   │
│ 4 立即复活      金币不足    │
│ 5 进攻姿态      冷却 3s     │
│ 6 防御姿态      可用        │
│ 7 移动姿态      当前        │
├────────────────────────────┤
│ Enter 确认  Esc 关闭  Q/E 翻页│
└────────────────────────────┘
```

按钮状态：

- `可用`：可以立即发送命令。
- `不可用`：显示明确原因，如金币不足、未脱战、阶段不允许、冷却中、当前已是该状态。
- `待确认`：高风险或消耗金币操作需要二次确认。
- `发送中`：命令已发送，等待同步或结果。
- `成功/失败`：显示协议回执或状态同步结果。

高风险操作必须二次确认：

- 立即复活。
- 花费金币呼叫空中支援。
- 飞镖确认发射。
- 英雄进入部署模式。
- 科技核心确认装配。
- 哨兵花费金币相关操作。

## 9. 资源与复活交互

资源页负责买弹、远程补血、复活。所有按钮必须显示消耗和可用条件。

应展示：

- 当前金币。
- 当前剩余允许发弹量。
- 是否脱战。
- 是否可远程补血。
- 是否可远程补弹。
- 复活读条总进度和当前进度。
- 是否可免费复活。
- 是否允许花费金币复活。
- 立即复活所需金币。

操作项：

- 兑换 17mm 允许发弹量。
- 兑换 42mm 允许发弹量。
- 远程兑换允许发弹量。
- 远程兑换血量。
- 确认复活。
- 兑换立即复活。

命令来源：

- `CommonCommand`

状态来源：

- `GlobalLogisticsStatus`
- `RobotDynamicStatus`
- `RobotRespawnStatus`
- `GlobalUnitStatus`

## 10. 性能体系与角色交互

性能体系选择在准备阶段非常关键，应作为右侧弹窗的角色页或准备阶段默认页。

步兵：

- 底盘性能：血量优先 / 功率优先。
- 发射性能：爆发优先 / 冷却优先。
- 选择后需要确认锁定。

英雄：

- 底盘性能：血量优先 / 功率优先。
- 发射性能：近战优先 / 远程优先。
- 选择后需要确认锁定。
- 若为远程优先，显示部署模式入口。

哨兵：

- 自动 / 半自动。
- 选择后需要确认锁定。
- 比赛阶段显示当前姿态、弱化状态和姿态切换。

命令来源：

- `RobotPerformanceSelectionCommand`
- `HeroDeployModeEventCommand`
- `SentryCtrlCommand`

状态来源：

- `RobotStaticStatus`
- `RobotPerformanceSelectionSync`
- `DeployModeStatusSync`
- `SentryStatusSync`

## 11. 英雄部署模式

英雄部署模式必须清楚提示代价，因为进入部署模式会造成底盘断电和图传画面断开，但自定义 UI 和小地图仍可用。

右侧弹窗应展示：

- 当前是否已部署。
- 当前是否满足可部署区域条件，如果协议或本地逻辑能判断。
- 进入部署模式按钮。
- 退出部署模式按钮。
- 进入部署倒计时。
- 部署收益：防御增益、射速上限提升、攻击基地增益。
- 部署代价：底盘断电、图传断开。

交互：

- 进入部署模式需要二次确认。
- 退出部署模式可直接执行或轻确认。

命令来源：

- `HeroDeployModeEventCommand`

状态来源：

- `DeployModeStatusSync`
- `RobotStaticStatus`
- `RobotDynamicStatus`
- `Buff`

## 12. 能量机关交互

能量机关不应常驻占用主屏，但其状态应进入告警和机制弹窗。

应展示：

- 未激活、正在激活、已激活。
- 当前已激活灯臂数量。
- 平均环数。
- 小能量/大能量阶段可由时间和状态推导。
- 可触发时进入当前告警。
- 已激活时展示队伍 Buff 和剩余收益时间。

操作：

- 激活能量机关。

命令来源：

- `RuneActivateCommand`

状态来源：

- `RuneStatusSync`
- `Event`
- `Buff`

## 13. 飞镖交互

飞镖交互属于高风险操作，必须放在右侧弹窗的机制页，并带二次确认。

应展示：

- 当前目标 ID。
- 目标含义：前哨站、基地固定目标、基地随机固定目标、基地随机移动目标、基地末端移动目标。
- 闸门状态：关闭、开启中、已开启。
- 当前是否可发射。
- 近期飞镖命中事件。
- 命中导致的遮挡、基地护甲展开、增益失效等事件提示。

操作：

- 选择目标。
- 开启/关闭闸门。
- 确认发射。

交互：

- 开启闸门需要确认。
- 确认发射必须二次确认。
- 发射后显示发送中，等待状态或事件反馈。

命令来源：

- `DartCommand`

状态来源：

- `DartSelectTargetStatusSync`
- `Event`

## 14. 哨兵交互

哨兵弹窗需要同时服务“姿态状态展示”和“低频指令发送”。

应展示：

- 当前控制方式：自动/半自动。
- 当前姿态：进攻、防御、移动。
- 是否弱化。
- 姿态切换冷却。
- 最近一次哨兵指令结果。
- 自动哨兵由云台手干预可能消耗金币的提示。

操作：

- 补血点补弹。
- 补给站实体补弹。
- 远程补弹。
- 远程回血。
- 确认复活。
- 确认花费金币复活。
- 切换为进攻姿态。
- 切换为防御姿态。
- 切换为移动姿态。

命令来源：

- `SentryCtrlCommand`

状态来源：

- `SentryStatusSync`
- `SentryCtrlResult`
- `RobotPerformanceSelectionSync`
- `GlobalLogisticsStatus`

## 15. 空中支援交互

空中支援在右侧弹窗的角色页或机制页展示。付费支援必须明确显示正在消耗金币。

应展示：

- 当前是否正在空中支援。
- 免费空中支援剩余时间。
- 付费空中支援已花费金币。
- 是否正在被雷达照射。
- 发射机构是否因雷达反制锁定。
- 反制相关事件。

操作：

- 免费呼叫空中支援。
- 花费金币呼叫空中支援。
- 中断空中支援。

交互：

- 花费金币呼叫需要二次确认。
- 中断支援可直接执行或轻确认。
- 正在付费消耗时给持续提示。

命令来源：

- `AirSupportCommand`

状态来源：

- `AirSupportStatusSync`
- `Event`

- 图传模块。
- 电容模块。
- 主控。

- 在线。

## 18. 判罚与遮挡

判罚和遮挡应当覆盖普通 UI 优先级。它们既要进入左侧告警，也要在中央区域或全屏遮罩中体现。

判罚类型：

- 黄牌。
- 双方黄牌。
- 红牌。
- 超功率。
- 超热量。
- 超射速。

应展示：

- 当前受罚类型。
- 当前受罚效果剩余时长。
- 当前累计判罚数量。
- 受罚造成的遮挡、扣血、锁定或断电提示。

遮挡来源：

- 黄牌/双方黄牌。
- 飞镖命中。
- 规则导致的小地图、自定义 UI、图传遮挡。

展示方式：

- 轻遮挡：边缘警示 + 倒计时。
- 重遮挡：中央半透明遮罩 + 原因 + 倒计时。
- 自定义 UI 被遮挡时，应显示规则允许范围内的最小提示，避免继续提供被遮挡的信息。

信息来源：

- `PenaltyInfo`
- `Event`

## 20. 第一版 MVP

第一版主 UI 建议按以下范围实现：

1. 顶部全局态势：阶段、时间、暂停、比分、基地、前哨、双方机器人血量、金币、科技/加密等级、链路。
2. 中央图传 HUD：准星、热量环、弹量、最近弹速、锁定状态、本机关键 Buff。
3. 底部本机状态：血量、热量、底盘能量、缓冲、等级、经验、脱战、远程补血/补弹可用。
4. 左侧告警事件流：按 2026 协议 Event、PenaltyInfo 和关键状态变化重做事件映射。
5. 右侧按键弹窗：资源页、角色页、机制页、状态页。
6. 只读小地图：本机、己方、雷达目标、基地/前哨、哨兵路径简化显示，不接收鼠标点击。
7. 复活面板：严格使用 `can_free_respawn`、`can_pay_for_respawn` 和费用字段。
8. 哨兵/飞镖/空中支援：先展示状态，再接入命令和回执。
